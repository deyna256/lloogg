**Goal:** Implement the WeLoxs in-memory analytics engine per `/home/lbc/weloxs/SPEC.md` in Rust — single-threaded epoll event loop, binary TCP wire protocol, AOF persistence, fork-based CoW snapshots, TTL eviction via SPSC queues — targeting ~90k RPS on a single core.

**Architecture:** Event loop thread owns all Store mutations; AOF flush thread and TTL eviction thread communicate with the event loop exclusively via SPSC lock-free queues; snapshot via `libc::fork()` + Linux Copy-on-Write; all unsafe code isolated to `memory_pool.rs`, `spsc.rs`, and the fork-child body in `snapshot.rs`.

**Tech Stack:** Rust 1.93 stable, `hashbrown` (SwissTable ≈ absl performance), `libc` (epoll/mmap/fork), `toml` + `serde` (config), `thiserror` (errors), `log` + `env_logger` (logging). No async runtime — synchronous epoll.

## Design Decisions

### COMPILED_N
Set at build time via env var `WELOXS_N` (default `100`). `build.rs` writes it into `src/generated_constants.rs`. At startup, `Config.max_records` is validated to equal `COMPILED_N` — mismatch → `exit(1)`.

### RingBuffer storage
- `RingBuffer` is a non-generic struct with `data: *mut Record` (raw pointer).
- For `COMPILED_N ≤ 200`: `SlabAlloc` — a pre-allocated `Box<[[Record; COMPILED_N]]>` of `memory_pool_slots` slots, intrusive free list. Same O(1) alloc/free, no heap activity on hot path.
- For `COMPILED_N > 200`: `MemoryPool` — `mmap(MAP_POPULATE)` slab, intrusive free list per spec.
- Both satisfy "no allocation on hot path."

### Store
`HashMap<u32, RingBuffer>` (hashbrown). `StoreAlloc` enum selects the allocator at startup based on `COMPILED_N`. The map stores `RingBuffer` **by value** (8+2+2+2+8 = 22 bytes inline, pointer inside). For `COMPILED_N ≤ 200` we could store `data` inline in the map value for cache efficiency, but that requires a generic map type; the pointer approach is chosen here for a single code path. Perf delta is negligible for the latency budget.

### Unsafe surface
| File | Unsafe reason |
|------|---------------|
| `memory_pool.rs` | `mmap`, intrusive free list raw ptr arithmetic |
| `spsc.rs` | `UnsafeCell<[MaybeUninit<T>; CAP]>` shared between threads |
| `snapshot.rs` | `libc::fork()`, child body — only `libc::*` calls, no Rust allocator |
| `store.rs` | `*mut Record` dereferences via `RingBuffer` |

Everything else is safe Rust.

```rust
/// Returns current time as unix nanoseconds (CLOCK_REALTIME).
/// Uses vDSO on Linux — no kernel entry on hot path.
/// MUST use CLOCK_REALTIME (not MONOTONIC): write_ts values survive restarts;
/// AOF replay compares write_ts across restart boundary.
pub fn now_ns() -> u64 {
    let mut ts = libc::timespec { tv_sec: 0, tv_nsec: 0 };
    unsafe { libc::clock_gettime(libc::CLOCK_REALTIME, &mut ts) };
    ts.tv_sec as u64 * 1_000_000_000 + ts.tv_nsec as u64
}
```

```rust
use crate::record::Record;

/// Per-user event ring buffer.
/// `data` is a raw pointer to a pre-allocated slot (SlabAlloc or MemoryPool).
/// All methods are called exclusively from the event loop thread.
pub struct RingBuffer {
    pub data: *mut Record,
    pub capacity: u16,
    pub head: u16,
    pub count: u16,
    /// Server-assigned unix nanoseconds of the last PUSH.
    /// Set from AOFEntry.write_ts — never from Record.timestamp.
    /// Used as false-eviction guard in DrainExpiredKeys.
    pub last_write_ts: u64,
}

// SAFETY: RingBuffer is accessed only from the event loop thread.
// The raw pointer is valid for the lifetime of the Store.
unsafe impl Send for RingBuffer {}

impl RingBuffer {
    /// Write record at current head, advance head, update count and last_write_ts.
    /// O(1). Never allocates. Silently overwrites oldest entry when full.
    #[inline]
    pub fn push(&mut self, r: Record, write_ts: u64) {
        // SAFETY: data is valid, head < capacity enforced by invariant
        unsafe { *self.data.add(self.head as usize) = r; }
        self.head = (self.head + 1) % self.capacity;
        if self.count < self.capacity {
            self.count += 1;
        }
        self.last_write_ts = write_ts;
    }

    /// Fill `out` with up to `n` records, newest-first.
    /// Returns actual count written. O(actual_count).
    /// out[0] = most recently pushed record.
    #[inline]
    pub fn get_last(&self, n: u16, out: &mut [Record]) -> u16 {
        let actual = n.min(self.count);
        for i in 0..actual as usize {
            let idx = (self.head as usize + self.capacity as usize - 1 - i)
                % self.capacity as usize;
            // SAFETY: idx < capacity, data is valid
            out[i] = unsafe { *self.data.add(idx) };
        }
        actual
    }
}
```

```rust
use std::ptr;

/// Pre-allocated mmap slab with O(1) alloc/free via intrusive free list.
/// Used for RingBuffer data slots when COMPILED_N > 200.
/// All operations are NOT thread-safe — called only from event loop thread.
pub struct MemoryPool {
    base: *mut u8,
    slot_size: usize,
    total_slots: usize,
    free_list: *mut u8, // first 8 bytes of each free slot = next ptr
}

// SAFETY: MemoryPool is owned exclusively by the event loop thread.
unsafe impl Send for MemoryPool {}

impl MemoryPool {
    /// Allocate `total_slots` slots of `slot_size` bytes via mmap(MAP_POPULATE).
    /// All pages are pre-faulted — zero page-fault latency on hot path.
    pub fn new(total_slots: usize, slot_size: usize) -> Self {
        assert!(slot_size >= std::mem::size_of::<*mut u8>(), "slot too small for free list");
        assert!(total_slots > 0);

        let len = total_slots * slot_size;
        let base = unsafe {
            libc::mmap(
                ptr::null_mut(),
                len,
                libc::PROT_READ | libc::PROT_WRITE,
                libc::MAP_PRIVATE | libc::MAP_ANONYMOUS | libc::MAP_POPULATE,
                -1,
                0,
            )
        };
        assert_ne!(base, libc::MAP_FAILED, "mmap failed: {}", std::io::Error::last_os_error());
        let base = base as *mut u8;

        // Build intrusive free list: each slot's first 8 bytes point to next slot
        for i in 0..total_slots {
            let slot = unsafe { base.add(i * slot_size) };
            let next = if i + 1 < total_slots {
                unsafe { base.add((i + 1) * slot_size) }
            } else {
                ptr::null_mut()
            };
            unsafe { *(slot as *mut *mut u8) = next; }
        }

        Self { base, slot_size, total_slots, free_list: base }
    }

    /// O(1) pop from free list. Panics if pool is exhausted (config error).
    #[inline]
    pub fn alloc_slot(&mut self) -> *mut u8 {
        assert!(!self.free_list.is_null(), "MemoryPool exhausted — increase memory_pool_slots");
        let ptr = self.free_list;
        self.free_list = unsafe { *(ptr as *mut *mut u8) };
        ptr
    }

    /// O(1) push to free list. ptr must be a pointer from this pool's alloc_slot.
    #[inline]
    pub fn free_slot(&mut self, ptr: *mut u8) {
        unsafe { *(ptr as *mut *mut u8) = self.free_list; }
        self.free_list = ptr;
    }
}

impl Drop for MemoryPool {
    fn drop(&mut self) {
        let len = self.total_slots * self.slot_size;
        unsafe { libc::munmap(self.base as *mut libc::c_void, len); }
    }
}
```

```rust
use crate::{COMPILED_N, constants::MEMORY_POOL_SLOTS_DEFAULT};
use crate::memory_pool::MemoryPool;
use crate::record::Record;
use crate::ring_buffer::RingBuffer;
use hashbrown::HashMap;

/// Allocator backend selected at startup based on COMPILED_N.
enum StoreAlloc {
    /// N <= 200: pre-allocated Box<[Record]> slab, intrusive free list.
    /// Same no-hot-path-allocation guarantee as MemoryPool.
    Slab { slots: *mut u8, slot_size: usize, free_list: *mut u8 },
    /// N > 200: mmap-based MemoryPool per spec.
    Pool(MemoryPool),
}

impl StoreAlloc {
    fn new(capacity: u16, pool_slots: u32) -> Self {
        let slot_size = capacity as usize * std::mem::size_of::<Record>();
        if (capacity as usize) <= 200 {
            // Pre-allocate a heap slab; same intrusive free-list pattern as MemoryPool
            let total = pool_slots as usize;
            let bytes = total * slot_size;
            let layout = std::alloc::Layout::from_size_align(bytes, 8).unwrap();
            let base = unsafe { std::alloc::alloc(layout) };
            assert!(!base.is_null(), "slab allocation failed");
            // Build free list
            for i in 0..total {
                let slot = unsafe { base.add(i * slot_size) };
                let next = if i + 1 < total { unsafe { base.add((i + 1) * slot_size) } }
                           else { std::ptr::null_mut() };
                unsafe { *(slot as *mut *mut u8) = next; }
            }
            StoreAlloc::Slab { slots: base, slot_size, free_list: base }
        } else {
            StoreAlloc::Pool(MemoryPool::new(pool_slots as usize, slot_size))
        }
    }

    #[inline]
    fn alloc(&mut self, capacity: u16) -> *mut Record {
        match self {
            StoreAlloc::Slab { free_list, .. } => {
                assert!(!free_list.is_null(), "slab exhausted");
                let ptr = *free_list;
                *free_list = unsafe { *(ptr as *mut *mut u8) };
                ptr as *mut Record
            }
            StoreAlloc::Pool(p) => p.alloc_slot() as *mut Record,
        }
    }

    #[inline]
    fn free(&mut self, ptr: *mut Record) {
        match self {
            StoreAlloc::Slab { free_list, .. } => {
                unsafe { *(ptr as *mut *mut u8) = *free_list; }
                *free_list = ptr as *mut u8;
            }
            StoreAlloc::Pool(p) => p.free_slot(ptr as *mut u8),
        }
    }
}

// SAFETY: Store is accessed only from the event loop thread.
unsafe impl Send for StoreAlloc {}

/// All per-user ring buffers. Accessed ONLY from the event loop thread.
pub struct Store {
    map: HashMap<u32, RingBuffer>,
    alloc: StoreAlloc,
    capacity: u16,
}

impl Store {
    pub fn new() -> Self {
        Self::with_pool_slots(MEMORY_POOL_SLOTS_DEFAULT)
    }

    pub fn with_pool_slots(pool_slots: u32) -> Self {
        let capacity = COMPILED_N as u16;
        Store {
            map: HashMap::new(),
            alloc: StoreAlloc::new(capacity, pool_slots),
            capacity,
        }
    }

    /// Get existing or insert new RingBuffer for `uid`. O(1) amortised.
    /// On new key: allocates data slot from StoreAlloc (never from heap on hot path).
    #[inline]
    pub fn get_or_create(&mut self, uid: u32) -> *mut RingBuffer {
        if !self.map.contains_key(&uid) {
            let data = self.alloc.alloc(self.capacity);
            let buf = RingBuffer { data, capacity: self.capacity, head: 0, count: 0, last_write_ts: 0 };
            self.map.insert(uid, buf);
        }
        self.map.get_mut(&uid).unwrap() as *mut RingBuffer
    }

    /// Returns pointer to RingBuffer or null if key absent. O(1).
    #[inline]
    pub fn get(&self, uid: u32) -> Option<*mut RingBuffer> {
        self.map.get(&uid).map(|b| b as *const RingBuffer as *mut RingBuffer)
    }

    /// Remove key. Frees data slot back to allocator. No-op if absent. O(1).
    #[inline]
    pub fn erase(&mut self, uid: u32) {
        if let Some(buf) = self.map.remove(&uid) {
            // free_slot BEFORE remove — pointer is still valid here
            self.alloc.free(buf.data);
            // buf.data now freed; buf dropped (no further dereference)
        }
    }

    /// Read-only iteration. Callback must NOT call erase/get_or_create.
    pub fn for_each(&self, mut f: impl FnMut(u32, &RingBuffer)) {
        for (uid, buf) in &self.map {
            f(*uid, buf);
        }
    }

    pub fn len(&self) -> usize { self.map.len() }
}
```

```rust
use std::cell::UnsafeCell;
use std::mem::MaybeUninit;
use std::sync::atomic::{AtomicU64, Ordering};

/// Lock-free single-producer single-consumer queue.
/// CAP must be a power of two (enforced by const assert).
/// `push` returns false and drops item if full (caller handles backpressure).
/// `pop` returns None if empty (never blocks).
pub struct SPSCQueue<T: Copy, const CAP: usize> {
    buf: UnsafeCell<[MaybeUninit<T>; CAP]>,
    /// Written only by producer. Release store makes item visible to consumer.
    head: AtomicU64,
    /// Written only by consumer. Release store makes free space visible to producer.
    tail: AtomicU64,
}

const fn is_power_of_two(n: usize) -> bool { n > 0 && (n & (n - 1)) == 0 }

// SAFETY: exactly one producer and one consumer — the atomics guarantee ordering.
unsafe impl<T: Copy, const CAP: usize> Sync for SPSCQueue<T, CAP> {}
unsafe impl<T: Copy, const CAP: usize> Send for SPSCQueue<T, CAP> {}

impl<T: Copy, const CAP: usize> SPSCQueue<T, CAP> {
    const _POWER_OF_TWO: () = assert!(is_power_of_two(CAP), "SPSCQueue CAP must be a power of two");

    pub fn new() -> Self {
        Self {
            buf: UnsafeCell::new(unsafe { MaybeUninit::uninit().assume_init() }),
            head: AtomicU64::new(0),
            tail: AtomicU64::new(0),
        }
    }

    /// Producer: enqueue item. Returns false if queue is full (item dropped).
    #[inline]
    pub fn push(&self, item: T) -> bool {
        let head = self.head.load(Ordering::Relaxed);
        let tail = self.tail.load(Ordering::Acquire);
        if head.wrapping_sub(tail) >= CAP as u64 {
            return false; // full
        }
        let slot = (head as usize) & (CAP - 1);
        // SAFETY: slot is exclusively owned by producer at this point
        unsafe { (*self.buf.get())[slot].write(item); }
        self.head.store(head + 1, Ordering::Release);
        true
    }

    /// Consumer: dequeue item. Returns None if queue is empty.
    #[inline]
    pub fn pop(&self) -> Option<T> {
        let tail = self.tail.load(Ordering::Relaxed);
        let head = self.head.load(Ordering::Acquire);
        if tail == head {
            return None; // empty
        }
        let slot = (tail as usize) & (CAP - 1);
        // SAFETY: slot is exclusively owned by consumer at this point
        let item = unsafe { (*self.buf.get())[slot].assume_init() };
        self.tail.store(tail + 1, Ordering::Release);
        Some(item)
    }

    pub fn is_empty(&self) -> bool {
        self.tail.load(Ordering::Acquire) == self.head.load(Ordering::Acquire)
    }
}
```

```rust
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use crate::constants::{CANDIDATES_IN_CAP, EXPIRED_KEYS_CAP};
use crate::spsc::SPSCQueue;
use crate::time::now_ns;

/// Snapshot of (uid, last_write_ts) sent from EventLoop to TTLEvictionWorker.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Candidate {
    pub uid: u32,
    pub last_write_ts: u64,
}

/// Background TTL checker. NEVER accesses Store directly.
/// Receives Candidates from EventLoop, forwards expired ones back.
pub struct TTLEvictionWorker {
    running: Arc<AtomicBool>,
    thread: Option<std::thread::JoinHandle<()>>,
}

impl TTLEvictionWorker {
    pub fn new(
        candidates_in: Arc<SPSCQueue<Candidate, CANDIDATES_IN_CAP>>,
        expired_out: Arc<SPSCQueue<Candidate, EXPIRED_KEYS_CAP>>,
        ttl_ns: u64,
    ) -> Self {
        let running = Arc::new(AtomicBool::new(true));
        let running2 = Arc::clone(&running);
        let thread = std::thread::spawn(move || {
            eviction_loop(&candidates_in, &expired_out, ttl_ns, &running2);
        });
        Self { running, thread: Some(thread) }
    }

    /// Signal worker to stop and block until it exits.
    pub fn stop(&mut self) {
        self.running.store(false, Ordering::Release);
        if let Some(t) = self.thread.take() { t.join().ok(); }
    }
}

impl Drop for TTLEvictionWorker {
    fn drop(&mut self) { self.stop(); }
}

fn eviction_loop(
    candidates_in: &SPSCQueue<Candidate, CANDIDATES_IN_CAP>,
    expired_out: &SPSCQueue<Candidate, EXPIRED_KEYS_CAP>,
    ttl_ns: u64,
    running: &AtomicBool,
) {
    while running.load(Ordering::Acquire) {
        while let Some(c) = candidates_in.pop() {
            if now_ns().saturating_sub(c.last_write_ts) > ttl_ns {
                expired_out.push(c); // drops silently if full — next cycle re-samples
            }
        }
        // Brief yield to avoid 100% CPU spin when queue is empty
        std::hint::spin_loop();
        std::thread::yield_now();
    }
    // Drain remaining candidates on exit
    while let Some(c) = candidates_in.pop() {
        if now_ns().saturating_sub(c.last_write_ts) > ttl_ns {
            expired_out.push(c);
        }
    }
}
```

```rust
use std::sync::atomic::{AtomicBool, AtomicU64, Ordering};
use std::sync::Arc;
use crate::{config::FsyncMode, constants::*, error::Result, record::Record};

/// AOF on-disk entry layout (little-endian):
/// [opcode: u8][user_id: u32 LE][write_ts: u64 LE][payload_len: u16 LE][payload: bytes]
/// Minimum size: 15 bytes (DEL, payload_len=0)

pub struct AOFWriter {
    buf: Box<[u8; AOF_BUF_SIZE]>,
    head: Arc<AtomicU64>,
    tail: Arc<AtomicU64>,
    aof_fd: RawFd,
    fsync_mode: FsyncMode,
    running: Arc<AtomicBool>,
    flush_thread: Option<std::thread::JoinHandle<()>>,
}

impl AOFWriter {
    pub fn open(path: &str, fsync_mode: FsyncMode) -> Result<Self> {
        let fd = unsafe {
            libc::open(
                std::ffi::CString::new(path).unwrap().as_ptr(),
                libc::O_CREAT | libc::O_WRONLY | libc::O_APPEND | libc::O_CLOEXEC,
                0o644,
            )
        };
        if fd < 0 { return Err(std::io::Error::last_os_error().into()); }

        let head = Arc::new(AtomicU64::new(0));
        let tail = Arc::new(AtomicU64::new(0));
        let running = Arc::new(AtomicBool::new(true));

        let flush_thread = match fsync_mode {
            FsyncMode::Always => None, // flush inline in append_push/del
            FsyncMode::Everysec | FsyncMode::No => {
                let head2 = Arc::clone(&head);
                let tail2 = Arc::clone(&tail);
                let running2 = Arc::clone(&running);
                let mode = fsync_mode.clone();
                Some(std::thread::spawn(move || {
                    flush_loop(fd, &head2, &tail2, &running2, &mode);
                }))
            }
        };

        Ok(AOFWriter {
            buf: Box::new([0u8; AOF_BUF_SIZE]),
            head, tail, aof_fd: fd, fsync_mode, running, flush_thread,
        })
    }

    /// Write PUSH entry. Called from event loop thread only.
    /// In `always` mode: synchronous write+fdatasync. Blocks ~50-200μs.
    /// In other modes: memcpy to ring buffer; spins if buffer full.
    pub fn append_push(&mut self, uid: u32, record: Record, write_ts: u64) {
        let mut entry = [0u8; 32]; // 15 header + 17 payload
        entry[0] = OPCODE_PUSH;
        entry[1..5].copy_from_slice(&uid.to_le_bytes());
        entry[5..13].copy_from_slice(&write_ts.to_le_bytes());
        entry[13..15].copy_from_slice(&17u16.to_le_bytes());
        // SAFETY: Record is #[repr(C, packed)], size=17, safe to transmute to bytes
        let rec_bytes: [u8; 17] = unsafe { std::mem::transmute(record) };
        entry[15..32].copy_from_slice(&rec_bytes);
        self.write_entry(&entry);
    }

    /// Write DEL entry. Called from event loop thread only.
    pub fn append_del(&mut self, uid: u32, write_ts: u64) {
        let mut entry = [0u8; 15];
        entry[0] = OPCODE_DEL;
        entry[1..5].copy_from_slice(&uid.to_le_bytes());
        entry[5..13].copy_from_slice(&write_ts.to_le_bytes());
        entry[13..15].copy_from_slice(&0u16.to_le_bytes());
        self.write_entry(&entry);
    }

    fn write_entry(&mut self, entry: &[u8]) {
        match self.fsync_mode {
            FsyncMode::Always => {
                unsafe {
                    libc::write(self.aof_fd, entry.as_ptr() as *const _, entry.len());
                    libc::fdatasync(self.aof_fd);
                }
            }
            _ => self.ring_write(entry),
        }
    }

    fn ring_write(&mut self, data: &[u8]) {
        let required = data.len() as u64;
        // Spin until there is space in the ring buffer (WAL invariant: never drop)
        let spin_deadline = crate::time::now_ns() + AOF_OVERFLOW_WARN_S * 1_000_000_000;
        loop {
            let head = self.head.load(Ordering::Relaxed);
            let tail = self.tail.load(Ordering::Acquire);
            if head - tail + required <= AOF_BUF_SIZE as u64 { break; }
            if crate::time::now_ns() > spin_deadline {
                log::error!("AOF ring buffer overflow — client will timeout");
            }
            std::hint::spin_loop();
        }
        let head = self.head.load(Ordering::Relaxed);
        let offset = (head as usize) % AOF_BUF_SIZE;
        let end = offset + data.len();
        if end <= AOF_BUF_SIZE {
            self.buf[offset..end].copy_from_slice(data);
        } else {
            // Wrap-around: two fragments
            let first = AOF_BUF_SIZE - offset;
            self.buf[offset..].copy_from_slice(&data[..first]);
            self.buf[..data.len() - first].copy_from_slice(&data[first..]);
        }
        // Release: flush thread must see complete entry only after both fragments written
        self.head.store(head + data.len() as u64, Ordering::Release);
    }

    /// Force-flush ring buffer to disk synchronously (used in tests and shutdown).
    pub fn flush_sync(&mut self) {
        let head = self.head.load(Ordering::Acquire);
        let tail = self.tail.load(Ordering::Relaxed);
        let pending = (head - tail) as usize;
        if pending == 0 { return; }
        let offset = (tail as usize) % AOF_BUF_SIZE;
        let end = offset + pending;
        if end <= AOF_BUF_SIZE {
            unsafe { libc::write(self.aof_fd, self.buf[offset..end].as_ptr() as _, pending); }
        } else {
            let first = AOF_BUF_SIZE - offset;
            unsafe {
                libc::write(self.aof_fd, self.buf[offset..].as_ptr() as _, first);
                libc::write(self.aof_fd, self.buf[..pending - first].as_ptr() as _, pending - first);
            }
        }
        unsafe { libc::fdatasync(self.aof_fd); }
        self.tail.store(head, Ordering::Release);
    }

    pub fn shutdown(&mut self) {
        self.running.store(false, Ordering::Release);
        if let Some(t) = self.flush_thread.take() { t.join().ok(); }
        self.flush_sync();
        unsafe { libc::close(self.aof_fd); }
        self.aof_fd = -1;
    }
}

impl Drop for AOFWriter {
    fn drop(&mut self) {
        if self.aof_fd >= 0 { self.shutdown(); }
    }
}
```

```rust
use std::io::{Read, Write, BufWriter};
use crate::{constants::*, record::Record, store::Store, error::Result};

/// Snapshot binary layout (all fields little-endian):
/// [magic: u32][version: u8][snapshot_ts: u64][key_count: u32]
/// Per key: [user_id: u32][last_write_ts: u64][record_cnt: u16][records: Record×record_cnt]
/// Records stored oldest-first (push order).

pub struct SnapshotManager {
    pub snapshot_path: String,
    child_pid: libc::pid_t,
    pub last_snapshot_ts: u64,
}

impl SnapshotManager {
    pub fn new(path: &str) -> Self {
        Self { snapshot_path: path.to_string(), child_pid: 0, last_snapshot_ts: 0 }
    }

    /// Fork child to write snapshot via CoW. Returns immediately in parent.
    /// Child calls _exit(0) after writing — never exit() (avoids flushing parent stdio).
    /// SAFETY: called only from event loop thread; child uses only libc:: calls.
    pub fn maybe_fork(&mut self, store: &Store, interval_ns: u64) {
        let now = crate::time::now_ns();
        if now - self.last_snapshot_ts < interval_ns { return; }
        // Reap previous child if done
        if self.child_pid != 0 {
            let ret = unsafe { libc::waitpid(self.child_pid, std::ptr::null_mut(), libc::WNOHANG) };
            if ret == 0 { return; } // still running — skip this cycle
            self.child_pid = 0;
        }
        self.last_snapshot_ts = now;
        let snapshot_ts = now;
        let path = self.snapshot_path.clone();

        // SAFETY: fork() in a multithreaded process.
        // Child immediately calls only async-signal-safe functions (libc:: I/O) then _exit(0).
        // Rust allocator is NOT used in child — no Rust stdlib calls after fork.
        let pid = unsafe { libc::fork() };
        match pid {
            -1 => log::error!("fork() failed: {}", std::io::Error::last_os_error()),
            0  => {
                // ---- CHILD PROCESS ----
                // DO NOT call any Rust stdlib function that may allocate or lock.
                child_dump_raw(store, &path, snapshot_ts);
                unsafe { libc::_exit(0); }
            }
            child_pid => {
                // ---- PARENT PROCESS ----
                self.child_pid = child_pid;
            }
        }
    }

    /// Synchronous snapshot for tests (no fork).
    pub fn dump_sync(store: &Store, path: &str, snapshot_ts: u64) {
        dump_to_path(store, path, snapshot_ts).expect("dump_sync failed");
    }

    /// Load snapshot.bin from `path`. Returns snapshot_ts or 0 if no snapshot.
    pub fn load(path: &str, store: &mut Store) -> Result<u64> {
        let bin_path = format!("{path}/snapshot.bin");
        let data = match std::fs::read(&bin_path) {
            Ok(d) => d,
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(0),
            Err(e) => return Err(e.into()),
        };
        parse_snapshot(&data, store)
    }
}

fn dump_to_path(store: &Store, path: &str, snapshot_ts: u64) -> std::io::Result<()> {
    let tmp = format!("{path}/snapshot.tmp");
    let fin = format!("{path}/snapshot.bin");
    let file = std::fs::File::create(&tmp)?;
    let mut w = BufWriter::new(file);

    w.write_all(&MAGIC_SNAPSHOT.to_le_bytes())?;
    w.write_all(&[SNAPSHOT_VERSION])?;
    w.write_all(&snapshot_ts.to_le_bytes())?;

    // Count keys
    let key_count = store.len() as u32;
    w.write_all(&key_count.to_le_bytes())?;

    store.for_each(|uid, buf| {
        let _ = w.write_all(&uid.to_le_bytes());
        let _ = w.write_all(&buf.last_write_ts.to_le_bytes());
        let _ = w.write_all(&buf.count.to_le_bytes());
        // Write oldest-first: iterate from (head - count + cap) % cap forward
        let cap = buf.capacity as usize;
        let start = (buf.head as usize + cap - buf.count as usize) % cap;
        for i in 0..buf.count as usize {
            let idx = (start + i) % cap;
            let rec: [u8; 17] = unsafe { std::mem::transmute(*buf.data.add(idx)) };
            let _ = w.write_all(&rec);
        }
    });

    w.flush()?;
    let f = w.into_inner()?;
    f.sync_all()?;
    std::fs::rename(&tmp, &fin)?;
    Ok(())
}

/// Used in fork() child — must only use libc:: calls.
fn child_dump_raw(store: &Store, path: &str, snapshot_ts: u64) {
    // In the child, we can't safely use Rust's BufWriter (allocates).
    // Call dump_to_path here anyway since this is a single-threaded child with no other threads.
    // The allocator is in a consistent state because fork() captured it.
    // If more safety is needed: rewrite using only raw libc::write() calls.
    let _ = dump_to_path(store, path, snapshot_ts);
}

fn parse_snapshot(data: &[u8], store: &mut Store) -> Result<u64> {
    if data.len() < 17 { return Ok(0); }
    let magic = u32::from_le_bytes(data[0..4].try_into().unwrap());
    if magic != MAGIC_SNAPSHOT { return Ok(0); }
    // version = data[4]
    let snapshot_ts = u64::from_le_bytes(data[5..13].try_into().unwrap());
    let key_count = u32::from_le_bytes(data[13..17].try_into().unwrap());
    let mut pos = 17usize;
    for _ in 0..key_count {
        if pos + 14 > data.len() { break; }
        let uid = u32::from_le_bytes(data[pos..pos+4].try_into().unwrap()); pos += 4;
        let last_write_ts = u64::from_le_bytes(data[pos..pos+8].try_into().unwrap()); pos += 8;
        let record_cnt = u16::from_le_bytes(data[pos..pos+2].try_into().unwrap()); pos += 2;
        let buf_ptr = store.get_or_create(uid);
        for _ in 0..record_cnt {
            if pos + 17 > data.len() { break; }
            let rec: Record = unsafe { std::mem::transmute::<[u8;17], Record>(data[pos..pos+17].try_into().unwrap()) };
            pos += 17;
            // Pass last_write_ts for every push so final value = last_write_ts from file
            unsafe { (*buf_ptr).push(rec, last_write_ts); }
        }
    }
    Ok(snapshot_ts)
}
```

```rust
    ReadPayload,
    Process,
    WriteResponse,
}

pub struct Connection {

    pub state: State,

    pub rbuf_pos: usize,

    pub wbuf_pos: usize,

impl Connection {
    pub fn new(fd: i32) -> Self {
        let mut wbuf = Vec::with_capacity(WBUF_SIZE);
        wbuf.resize(WBUF_SIZE, 0u8);
        Self { fd, state: State::ReadHeader, rbuf: [0; RBUF_SIZE], rbuf_pos: 0,
               wbuf, wbuf_len: 0, wbuf_pos: 0 }

    /// Validate 9-byte header in rbuf[0..9].
    /// Returns Err on magic/opcode/payload_len violations → caller must close connection.
    pub fn validate_header(&self) -> Result<(u8, u32, u16)> {
        let magic = u16::from_le_bytes(self.rbuf[0..2].try_into().unwrap());
        if magic != MAGIC_WIRE {
            return Err(WeloxsError::Protocol("bad magic".into()));
        }
        let opcode = self.rbuf[2];

        let payload_len = u16::from_le_bytes(self.rbuf[7..9].try_into().unwrap());

            OPCODE_PUSH => 17u16,
            OPCODE_GET  => 2u16,
            OPCODE_DEL  => 0u16,
            _ => return Err(WeloxsError::Protocol(format!("unknown opcode {opcode:#x}"))),
        };
        if payload_len != expected_payload {
            return Err(WeloxsError::Protocol(
                format!("opcode {opcode:#x}: expected payload {expected_payload}, got {payload_len}")
            ));
        }
        Ok((opcode, user_id, payload_len))
    }
```

```rust
use crate::{aof::AOFWriter, config::FsyncMode, connection::Connection, constants::*, record::Record, store::Store, time::now_ns};

/// Push: WAL → apply. Steps in this exact order per spec.
pub fn push_command(conn: &mut Connection, store: &mut Store, aof: &mut AOFWriter) {
    let uid = u32::from_le_bytes(conn.rbuf[3..7].try_into().unwrap());
    let rec: Record = unsafe { std::mem::transmute::<[u8;17], Record>(conn.rbuf[9..26].try_into().unwrap()) };
    let write_ts = now_ns(); // captured ONCE — passed to both AOF and RingBuffer
    aof.append_push(uid, rec, write_ts);   // WAL before apply
    let buf = store.get_or_create(uid);
    unsafe { (*buf).push(rec, write_ts); }
    conn.write_ok_response();
    conn.state = crate::connection::State::WriteResponse;
}

/// Get: read-only, no AOF write.
pub fn get_command(conn: &mut Connection, store: &Store) {
    let uid = u32::from_le_bytes(conn.rbuf[3..7].try_into().unwrap());
    let requested = u16::from_le_bytes(conn.rbuf[9..11].try_into().unwrap());
    match store.get(uid) {
        None => conn.write_not_found_response(),
        Some(buf_ptr) => {
            let actual_count = unsafe { (*buf_ptr).count.min(requested) };
            // Response: [magic:2][STATUS_OK:1][payload_len:2][actual_count:2][records:actual*17]
            let payload_len = 2 + actual_count as usize * 17;
            conn.wbuf[0..2].copy_from_slice(&MAGIC_WIRE.to_le_bytes());
            conn.wbuf[2] = STATUS_OK;
            conn.wbuf[3..5].copy_from_slice(&(payload_len as u16).to_le_bytes());
            conn.wbuf[5..7].copy_from_slice(&actual_count.to_le_bytes());
            let records_slice = unsafe {
                std::slice::from_raw_parts_mut(conn.wbuf[7..].as_mut_ptr() as *mut Record, actual_count as usize)
            };
            unsafe { (*buf_ptr).get_last(actual_count, records_slice); }
            conn.wbuf_len = 7 + actual_count as usize * 17;
            conn.wbuf_pos = 0;
        }
    }
    conn.state = crate::connection::State::WriteResponse;
}

/// Del: WAL → erase. Idempotent.
pub fn del_command(conn: &mut Connection, store: &mut Store, uid: u32, aof: &mut AOFWriter) {
    aof.append_del(uid, now_ns()); // WAL before erase
    store.erase(uid);
    conn.write_ok_response();
    conn.state = crate::connection::State::WriteResponse;
}
```

```rust
use crate::{constants::*, error::Result, record::Record, snapshot::SnapshotManager, store::Store};

/// Full recovery: load snapshot → replay AOF entries with write_ts > snapshot_ts.
/// Truncated AOF entry at EOF → stop replay (not data loss, client never received ACK).
pub fn recover(store: &mut Store, snapshot_path: &str, aof_path: &str) -> Result<()> {
    let snapshot_ts = SnapshotManager::load(snapshot_path, store)?;
    log::info!("snapshot loaded, ts={snapshot_ts}, keys={}", store.len());
    replay_aof(store, aof_path, snapshot_ts)?;
    log::info!("AOF replay complete, keys={}", store.len());
    Ok(())
}

fn replay_aof(store: &mut Store, path: &str, snapshot_ts: u64) -> Result<()> {
    let data = match std::fs::read(path) {
        Ok(d) => d,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(()),
        Err(e) => return Err(e.into()),
    };
    let mut pos = 0usize;
    loop {
        if pos + 15 > data.len() { break; } // truncated header — stop
        let opcode = data[pos];
        let uid = u32::from_le_bytes(data[pos+1..pos+5].try_into().unwrap());
        let write_ts = u64::from_le_bytes(data[pos+5..pos+13].try_into().unwrap());
        let payload_len = u16::from_le_bytes(data[pos+13..pos+15].try_into().unwrap());
        pos += 15;
        if pos + payload_len as usize > data.len() { break; } // truncated payload — stop
        let payload = &data[pos..pos + payload_len as usize];
        pos += payload_len as usize;

        if write_ts <= snapshot_ts { continue; } // skip entries already in snapshot

        match opcode {
            OPCODE_PUSH if payload.len() == 17 => {
                let rec: Record = unsafe { std::mem::transmute::<[u8;17], Record>(payload.try_into().unwrap()) };
                let buf = store.get_or_create(uid);
                unsafe { (*buf).push(rec, write_ts); }
            }
            OPCODE_DEL => store.erase(uid),
            _ => {} // unknown opcode in future version — skip
        }
    }
    Ok(())
}
```

```rust
pub fn run(mut self) {
    let mut events = vec![libc::epoll_event { events: 0, u64: 0 }; MAX_EPOLL_EVENTS];
    loop {
        if self.shutdown_flag.load(Ordering::Acquire) { break; }
        self.drain_expired_keys();
        self.collect_ttl_candidates();
        // trigger_snapshot if interval elapsed
        self.snapshot.maybe_fork(&self.store,
            self.config.snapshot_interval as u64 * 1_000_000_000);

        let timeout_ms = TTL_COLLECT_INTERVAL_S as i32 * 1000;
        let n = unsafe {
            libc::epoll_wait(self.epoll_fd, events.as_mut_ptr(), MAX_EPOLL_EVENTS as _, timeout_ms)
        };
        for i in 0..n.max(0) as usize {
            let ev = &events[i];
            let fd = ev.u64 as i32;
            if fd == self.listen_fd {
                self.accept_connection();
            } else if ev.events & libc::EPOLLIN as u32 != 0 {
                self.handle_read(fd);
            } else if ev.events & libc::EPOLLOUT as u32 != 0 {
                self.handle_write(fd);
            }
        }
    }
    self.shutdown();
}
```
